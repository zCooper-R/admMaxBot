# Example

Папка `Example/` — это библиотека эталонных универсальных шаблонов для Django-проектов.

Назначение:
- дать готовую базу инструкций для Codex/Cursor;
- ускорить запуск новых проектов без ручной сборки правил;
- обеспечить единый стандарт архитектурных и ревью-практик.

Что внутри универсальное:
- `Example/AGENTS.md`
- `Example/PLANS.md`
- `Example/.codex/config.toml`
- `Example/.codex/agents/*.toml`
- `Example/.codex/skills/*/SKILL.md`

Правила использования:
- файлы в `Example/` считаются эталоном;
- эти файлы не редактируются при адаптации конкретного проекта;
- для проекта создаются рабочие копии вне `Example/` (в корне и в `.codex/`);
- адаптируются только рабочие копии.

Как переносить в другой Django-проект:
1. Скопировать папку `Example/` целиком.
2. Сделать копии шаблонов в целевые пути проекта.
3. Адаптировать копии под структуру, стек, инфраструктуру и бизнес-контекст проекта.
4. Оставить `Example/` в неизменном виде как базовый reference.
